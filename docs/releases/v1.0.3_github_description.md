# Ubuntu Hello v1.0.3 - Dynamic Versioning & Security Hardening

This release introduces dynamic build-time Git version resolution for packaging/installation, process-wide umask hardening for file creation permissions, and defense-in-depth input sanitization.

---

## 🏷️ Dynamic Build-Time Versioning

*   **Build-time Git Detection**:
    *   Updated the Meson build configuration to dynamically detect Git status during setup and bake the precise commit description directly into python modules at compile/install time.
    *   Refactored the version detection logic in the main GUI window and setup wizard to recognize development build tags automatically when installed system-wide.

## 🔒 Security & Permission Hardening

*   **Process Umask Hardening**:
    *   Enforced process-wide `umask 077` across the Python CLI, configurator GUI, onboarding wizard, and face comparison subprocesses.
    *   Guarantees that all sensitive files (facial models, keyring auto-unlocking credentials, webcam snapshots, log files) are created with restricted owner-only permissions (`0o600` for files, `0o700` for directories), preventing race conditions (TOCTOU) and privacy leaks.
*   **Subprocess Input Sanitization**:
    *   Ported strict username format validation checks directly into the face comparison subprocess (`compare.py`), defending against potential path traversal attacks when invoked independently of PAM or the main CLI.

## 📥 Installation & Upgrade

### Universal Installer (Recommended)
```bash
curl -fsSL https://raw.githubusercontent.com/ventura8/ubuntu-hello/master/install.sh | sudo bash
```

### Ubuntu PPA
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```
