# 🚀 Ubuntu Hello v1.2.3 Release

Welcome to the **v1.2.3** release of **Ubuntu Hello**! This release adds support for **Ubuntu 22.04 LTS (jammy)**: the PPA now publishes a jammy build ([#17](https://github.com/ventura8/ubuntu-hello/issues/17)), and a new CI cell and the booted-OS tier keep it working. Tests written for this port found and fixed three real bugs in the PAM module and the CLI, including `ubuntu-hello disable` emptying `config.ini`. SonarQube Cloud now sees the C++ PAM module's coverage too.

---

## ✨ What's in v1.2.3

*   **🐧 New: Ubuntu 22.04 (jammy) support ([#17](https://github.com/ventura8/ubuntu-hello/issues/17)).** On 22.04, `apt update` failed with *"does not have a Release file"* because the PPA only built noble and resolute. It now builds jammy too. Jammy ships meson 0.61, GTK 4.6, PyGObject 3.42 and Python 3.10, so:
    *   The build no longer needs meson 0.64. `install_data(preserve_path:)` became a per-file install that keeps the `cli/`, `recorders/` and `rubberstamps/` layout.
    *   Settings and the setup wizard load on GTK 4.6. `GtkPicture:content-fit` (4.8) is dropped at load time, where GTK 4.6's default scaling already looks the same. The wizard's `GtkCenterBox` children use typed `<child>` elements instead of the 4.10 `*-widget` properties.
    *   Confirmation dialogs fall back to a small modal window where GTK has no `Gtk.AlertDialog` (4.10).
    *   On 22.04 the dropdowns in Settings have no type-ahead search. PyGObject 3.42 cannot pass GTK the search expression, so they are plain dropdowns there. Everything else works the same.
    *   The KDE theme probe installs `kreadconfig5` where KF6 does not exist (`libkf6config-bin | libkf5config-bin`).
*   **✅ Verified on a booted 22.04.** The booted-OS tier passes on a clean 22.04 cloud image. It covers the package install, face-auth PAM through `sudo`, the greeter rule, reboot persistence and purge. On 22.04 the polkit agent helper is setuid (polkit 0.105), so there is no sandbox to relax and the drop-in has no effect. The tier checks that instead of simulating a sandbox. v1.2.2 and older were built for 26.04 only, so on 22.04 there is no previous release to upgrade from.
*   **🐛 Fix: `ubuntu-hello disable` could empty `config.ini`.** On a config without the `disabled` key, the in-place rewrite crashed halfway and left a 0-byte file. It also reported success without changing anything when the line was spelled `disabled=false`. It now uses the same section-aware, atomic editor as Settings. It adds the key when missing, keeps comments, and a failed write leaves the old file intact.
*   **🐛 Fix: the PAM module's "Unknown error" message read past its string.** `S("Unknown error: ") + status` added the exit code to a `char *`, which is pointer arithmetic, not string concatenation. An unexpected compare exit code showed the user bytes from past the end of the message. It now prints the code.
*   **🐛 Fix: a PAM password task that never started could abort the host process.** `optional_task::stop()` joined or cancelled a thread that did not exist when the task was never activated, for example the password watcher under `pam_sm_open_session`. It now returns early.
*   **🐛 Smaller fixes.**
    *   `ubuntu-hello test` no longer crashes on a model whose `data` list is empty, and prints its resolution as width × height.
    *   `compare.py` no longer divides by zero on an empty camera frame.
*   **🔎 Coverage and duplication (SonarQube Cloud).**
    *   The Python gate now measures the same files Sonar does. The untested `cli/*.py` modules were never counted locally. 150+ new tests take the combined Python coverage to **97%**.
    *   The C++ PAM module now uploads gcov coverage (`gcovr --sonarqube`), with a new `pam-main` test for `main.cc`'s gates, error reporting, helper sanitising and `pam_sm_*` entry points.
    *   The one duplicated block (`detect_desktop()`, in both the theme probe and the wallet backend) is now shared.

No new config keys and no new or changed translatable strings.

## 🖥️ Desktop / Greeter / Wallet Compatibility

Face auth via PAM (`common-auth`; `system-auth` via authselect on Fedora; hand-wired on Arch) remains desktop-agnostic with **GDM, SDDM, LightDM**:

| Desktop | Face auth | Theme follow | Session wallet auto-unlock |
|---------|-----------|--------------|----------------------------|
| **GNOME / Ubuntu** | Yes | Yes | GNOME Keyring (`pam_gnome_keyring`) |
| **KDE Plasma** | Yes | Yes | **KWallet** (`pam_kwallet5`) |
| **XFCE** | Yes | Yes | GNOME Keyring when present |
| **Cinnamon** | Yes | Yes | GNOME Keyring when present |
| **MATE** | Yes | Yes | GNOME Keyring when present |
| **Budgie** | Yes | Yes | GNOME Keyring when present |
| **LXQt** | Yes | Yes | GNOME Keyring when present |

CI compat cells (parallel): `baseline`, `gnome`, `kde`, `xfce`, `cinnamon`, `mate`, `budgie`, `lxqt` on Ubuntu 26.04, and **new** `jammy` on Ubuntu 22.04 (build, unit tests, Settings E2E and the PAM module's C++ tests on meson 0.61, GTK 4.6, PyGObject 3.42, Python 3.10). The booted-OS tier runs on `ubuntu`, `fedora` and `arch` for same-repository release pull requests (`feature/v*`) and on demand.

## 📥 Installation

Download assets from the [GitHub Release](https://github.com/ventura8/ubuntu-hello/releases/tag/v1.2.3) page. Verify against `SHA256SUMS` before installing. Download this release's assets into an empty/clean directory before running these commands — the wildcards below match by filename pattern, and leftover assets from another version in the same directory can make a package manager see multiple matches (or, for the AppImage command, pass a second matched file as a stray argument).

### Method 1: Quick Install (from release tag)
Download and review [`install.sh`](https://github.com/ventura8/ubuntu-hello/blob/v1.2.3/install.sh) from the **v1.2.3** tag, then run `bash install.sh` locally.

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```
Builds for Ubuntu **22.04 (jammy)**, 24.04 (noble) and 26.04 (resolute), and derivatives on them (Linux Mint 21 / 22). **On 22.04, use the PPA**: the `.deb` Release assets below are built on 26.04 and do not install there.

### Method 3: Debian `.deb` (amd64 + arm64)
```bash
sudo apt install ./ubuntu-hello_*_$(dpkg --print-architecture).deb ./ubuntu-hello-gtk_*_$(dpkg --print-architecture).deb
```

### Method 4: Fedora RPM (amd64 + arm64)
```bash
sudo dnf install ./ubuntu-hello-[0-9]*fc44*.$(uname -m).rpm ./ubuntu-hello-gtk-*fc44*.$(uname -m).rpm
```

### Method 5: openSUSE RPM (amd64 + arm64)
```bash
sudo zypper install ./ubuntu-hello-[0-9]*lp160*.$(uname -m).rpm ./ubuntu-hello-gtk-*lp160*.$(uname -m).rpm
```

### Method 6: Arch Linux (amd64 only)
```bash
sudo pacman -U ./ubuntu-hello-[0-9]*.pkg.tar.zst ./ubuntu-hello-gtk-*.pkg.tar.zst
```

### Method 7: Snap (classic, amd64 only)
```bash
sudo snap install --dangerous --classic ubuntu-hello_*_amd64.snap
sudo snap run ubuntu-hello.host-install
```

### Method 8: AppImage (installer, amd64 + arm64)
```bash
chmod +x Ubuntu-Hello-*-$(uname -m).AppImage
./Ubuntu-Hello-*-$(uname -m).AppImage --install
```

### Method 9: Flatpak (installer, amd64 only)
```bash
flatpak install --user ./com.github.ventura8.UbuntuHello-*.flatpak && \
    flatpak run --command=ubuntu-hello-host-install com.github.ventura8.UbuntuHello
```
Approve the polkit prompt on the host-install step to install PAM and system files.

## 📋 Changelog (v1.2.3)

*   **Version:** `VERSION` is **1.2.3**.
*   **Ubuntu 22.04 support ([#17](https://github.com/ventura8/ubuntu-hello/issues/17)):**
    *   `release.yml` uploads a jammy PPA build.
    *   The meson floor is 0.61 (per-file Python install, since `preserve_path` needs 0.64).
    *   `gtk4compat` gains `adapt_ui_xml()`, an `AlertDialog` fallback and `gtk_expressions_supported()`.
    *   `onboarding.ui` uses typed `GtkCenterBox` children.
    *   `debian/control` and `uh-apt-deps.sh` fall back to `libkf5config-bin`.
*   **CI:**
    *   New `jammy` compat cell (`docker/Dockerfile.ci.jammy`); `check.yml` now has 18 runners.
    *   The coverage stage builds with gcov and uploads `cpp-coverage.xml`.
    *   `--cov` targets the `src` dirs, so never-imported modules count.
    *   The booted-OS tier handles setuid-helper polkit and a series with no installable previous release.
*   **Fixes:**
    *   `cli/disable.py` edits `config.ini` atomically through `config_edit`.
    *   PAM `ubuntu_hello_error()` builds its message as a `std::string`.
    *   `optional_task::stop()` handles a task that never started.
    *   `cli/test.py` handles empty models and prints width × height.
    *   `compare.py` checks for an empty histogram before dividing.
*   **Tests:**
    *   New `tests/pam_main_test.cc`, plus tests for `cli/*`, `compare.py`, `init.py`, `frame_text.py`, the recorders and `config_ensure.py`.
    *   The test suite now passes on Python 3.10: linked `gi` mocks, a correctly typed `malloc` in `test_auth_helper.py`, and `patch()` ordering in `test_rubberstamps.py`.
*   **Docs:** README *Supported releases*; the *Oldest supported release* rules in `docs/INSTRUCTIONS.md` and `AGENTS.md`; CI skill docs.
