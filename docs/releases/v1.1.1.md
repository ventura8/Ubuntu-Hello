# 🚀 Ubuntu Hello v1.1.1 Release

Welcome to the **v1.1.1** release of **Ubuntu Hello**! This patch restores the **login keyring or KWallet** password from sealed credentials **before** uninstall / `apt remove` deletes `/etc/ubuntu-hello`, hardens the post-install setup wizard (skip when faces are already enrolled; lock/log under `/run/ubuntu-hello/` instead of world-writable `/tmp`), and tightens `ubuntu-hello keyring restore` so a bare restore targets the selected user while `restore --all` is the explicit multi-user sweep used by packaging.

---

## ✨ Key Enhancements in v1.1.1

*   **🔐 Uninstall Wallet Restore (GNOME Keyring and KWallet)**:
    *   `uninstall.sh` and `debian/ubuntu-hello.prerm` run `timeout 120 ubuntu-hello keyring restore --all` **before** `rm -rf /etc/ubuntu-hello`.
    *   New `keyring_restore.py` unseals TPM or `UH1:` login passwords and talks to each user’s session bus (never logs the password; failures warn and **do not** abort removal).
    *   **GNOME Keyring**: D-Bus `ChangeWithMasterPassword` with old=new=sealed password `P` (succeeds when the wallet already unlocks with `P`; cannot discover a divergent wallet password).
    *   **KWallet**: verification-only via `pamOpen` (PBKDF2-SHA512 hash from the wallet salt file). Does **not** reset the KWallet password — if verification fails, set it in System Settings.
    *   `ubuntu-hello keyring disable` stays delete-only (no restore).
*   **🖥️ Desktop / greeter / wallet coverage (unchanged targets, restore-aware)**:
    *   Face auth via `common-auth` stays desktop-agnostic with **GDM, SDDM, LightDM**.
    *   Restore uses a **private** D-Bus connection per user’s `DBUS_SESSION_BUS_ADDRESS` (not a shared `bus_get_sync`), so multi-user uninstall hits the right session.
    *   Explicit coverage for **every** supported desktop:

        | Desktop | Face auth | Theme follow | Session wallet auto-unlock | Uninstall restore |
        |---------|-----------|--------------|----------------------------|-------------------|
        | **GNOME / Ubuntu** | Yes | Yes | GNOME Keyring (`pam_gnome_keyring`) | `ChangeWithMasterPassword` |
        | **KDE Plasma** | Yes | Yes | **KWallet** (`pam_kwallet5`) | `pamOpen` verification |
        | **XFCE** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
        | **Cinnamon** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
        | **MATE** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
        | **Budgie** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
        | **LXQt** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |

    *   CI compat cells (still parallel, Ubuntu 26.04): `baseline`, `gnome`, `kde`, `xfce`, `cinnamon`, `mate`, `budgie`, `lxqt`.
*   **🧹 Hardened Post-Install Wizard**:
    *   `install.sh` and `ubuntu-hello-gtk` dpkg postinst launch the wizard **only when no face models are enrolled** (`find … -type f`; symlink-only models do not count).
    *   `ubuntu-hello.postinst` no longer launches a second UI (gtk postinst owns the wizard).
    *   Lock and log moved off `/tmp` to `/run/ubuntu-hello/postinstall.lock` and `postinstall.log` (`0700` dir, `0600` files, `O_NOFOLLOW` / `O_EXCL`). Read with `sudo cat /run/ubuntu-hello/postinstall.log`.
*   **🧰 Keyring CLI**:
    *   `ubuntu-hello keyring restore` restores the CLI-selected user (`-U` / elevation).
    *   `ubuntu-hello keyring restore --all` sweeps every sealed user (packaging path). Extra args / positional usernames are usage errors.
    *   Usage string and restore messages filled for all Whisper locales.
*   **🧪 Tests & CI**:
    *   `tests/test_keyring_restore.py` (D-Bus reply validation, private connections, per-user bus, KWallet `pamOpen`).
    *   `tests/test_uninstall_keyring_restore.py` (anchored `rm -rf /etc/ubuntu-hello` so `/etc/ubuntu-hello-gtk` is not matched; asserts `--all` + `timeout 120`).
    *   Coverage stage now includes `keyring_restore` at 100% with the other keyring modules.

## 📥 Installation

### Method 1: Quick Install (Recommended)
Open your terminal and run the universal installer:
```bash
curl -fsSL https://raw.githubusercontent.com/ventura8/ubuntu-hello/master/install.sh | sudo bash
```

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```

### Method 3: Debian / Manual Package
Download the attached `.deb` package for your architecture, then install it using `apt` or `gdebi`:
```bash
sudo apt install ./ubuntu-hello_1.1.1-1ppa1_amd64.deb
```
