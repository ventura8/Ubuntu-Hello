# 🚀 Ubuntu Hello v1.2.4 Release

Welcome to the **v1.2.4** release of **Ubuntu Hello**! This is a quality release: SonarQube Cloud coverage goes from 87% to over 90%, with new tests for the PAM module's Enter-key device and theme detection. Nothing changes for users.

---

## ✨ What's in v1.2.4

*   **🔎 SonarQube Cloud coverage above 90%.** Sonar reported **87%**, held down by the C++ PAM module's branch coverage (38%). Most of those branches were not decisions in the source: gcc adds an exception-unwinding edge for every call that may throw, and no test can choose to take one. The C++ report now leaves out those and the branches gcc proves unreachable (`gcovr --exclude-throw-branches --exclude-unreachable-branches`), which drops about 300 of them. Overall coverage is now **90.7%**.
*   **🧪 New tests.**
    *   The PAM module's Enter-key device (`enter_device.cc`, used by the `input` workaround) had no tests. `pam-main` now runs it with libevdev's uinput calls stubbed: a refused `/dev/uinput`, a full Enter press, and a failed write at each step. It goes from 0% to 100%.
    *   Theme detection: the light and "no answer" results for KDE, XFCE, MATE and LXQt, the GTK icon-theme fallback, and `ThemeWatcher` surviving a missing monitor tool, a broken pipe and errors on shutdown.

No product code changes, no new config keys and no new or changed translatable strings.

## 📥 Installation

Download assets from the [GitHub Release](https://github.com/ventura8/ubuntu-hello/releases/tag/v1.2.4) page. Verify against `SHA256SUMS` before installing. Download this release's assets into an empty/clean directory before running these commands — the wildcards below match by filename pattern, and leftover assets from another version in the same directory can make a package manager see multiple matches (or, for the AppImage command, pass a second matched file as a stray argument).

### Method 1: Quick Install (from release tag)
Download and review [`install.sh`](https://github.com/ventura8/ubuntu-hello/blob/v1.2.4/install.sh) from the **v1.2.4** tag, then run `bash install.sh` locally.

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```
Builds for Ubuntu **22.04 (jammy)**, 24.04 (noble) and 26.04 (resolute), and derivatives on them (Linux Mint 21 / 22). **On 22.04, use the PPA**: the `.deb` Release assets below are built on 26.04 and do not install there.

### Method 3: Debian `.deb` (amd64 + arm64)
```bash
sudo apt install ./ubuntu-hello_*_$(dpkg --print-architecture).deb ./ubuntu-hello-gtk_*_$(dpkg --print-architecture).deb
```

### Method 4: Fedora RPM (amd64 + arm64)
```bash
sudo dnf install ./ubuntu-hello-[0-9]*fc44*.$(uname -m).rpm ./ubuntu-hello-gtk-*fc44*.$(uname -m).rpm
```

### Method 5: openSUSE RPM (amd64 + arm64)
```bash
sudo zypper install ./ubuntu-hello-[0-9]*lp160*.$(uname -m).rpm ./ubuntu-hello-gtk-*lp160*.$(uname -m).rpm
```

### Method 6: Arch Linux (amd64 only)
```bash
sudo pacman -U ./ubuntu-hello-[0-9]*.pkg.tar.zst ./ubuntu-hello-gtk-*.pkg.tar.zst
```

### Method 7: Snap (classic, amd64 only)
```bash
sudo snap install --dangerous --classic ubuntu-hello_*_amd64.snap
sudo snap run ubuntu-hello.host-install
```

### Method 8: AppImage (installer, amd64 + arm64)
```bash
chmod +x Ubuntu-Hello-*-$(uname -m).AppImage
./Ubuntu-Hello-*-$(uname -m).AppImage --install
```

### Method 9: Flatpak (installer, amd64 only)
```bash
flatpak install --user ./com.github.ventura8.UbuntuHello-*.flatpak && \
    flatpak run --command=ubuntu-hello-host-install com.github.ventura8.UbuntuHello
```
Approve the polkit prompt on the host-install step to install PAM and system files.
