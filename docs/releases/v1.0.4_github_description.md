# Ubuntu Hello v1.0.4 - CSD Styling, Dynamic Themes & Performance Tuning

This release brings a comprehensive visual modernization conforming to modern Ubuntu 26.04 (Yaru style / GNOME HIG) aesthetics, featuring client-side titlebars (HeaderBars), dynamic system theme/accent synchronization, webcam aspect-fit layout fixes, host animation alignment, and multi-threaded webcam initialization to prevent application interface lag.

---

## 🎨 Ubuntu 26.04 CSD Theme Integration

*   **Client-Side Titlebars (HeaderBar CSD)**:
    *   Replaced classic window headers with native GTK titlebars in the onboarding setup wizard and main configuration application, providing a premium CSD look matching modern GNOME applications.
*   **Dynamic Theme & Accent Matching**:
    *   Replaced hardcoded hex colors with native GTK symbolic variables (`@theme_selected_bg_color` / `@theme_selected_fg_color`), making the UI dynamically adapt to the user's host color palette, chosen system accent color, and light/dark preference.
    *   Redesigned notebook tab controls to look like a modern vertical navigation sidebar.

## 📷 Webcam Aspect-Fit & Layout Calibration

*   **Widescreen Fit without Crop**:
    *   Recalibrated the camera preview scaling computation using static layout constraints. This resolves the GtkImage resize loop that pushed lower settings list controls out of screen bounds.
    *   Guarantees camera frames scale to touch widget boundaries exactly with zero horizontal/vertical cropping.

## ⚡ Background Thread Camera Init

*   **No UI Lag/Freeze**:
    *   Offloaded webcam hardware check and initialization to background daemon threads, running `cv2.VideoCapture` asynchronously.
    *   Schedules rendering frames and updates back to the GTK main thread via `GLib.idle_add`, eliminating the 1-second GUI freeze when loading the Video tab or switching devices.

## 🎬 Native Animation Synchronization

*   **Elevated Animation Sync**:
    *   Synced window stack transitions and animations with host user settings (`org.gnome.desktop.interface enable-animations`), maintaining identical styling behavior when running as root via `pkexec`.

```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
```
