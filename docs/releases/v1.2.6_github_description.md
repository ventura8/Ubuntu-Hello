# Ubuntu Hello v1.2.6 - Code Quality Cleanup

This is a maintenance release: it clears the last open SonarCloud issue in the PAM module and fixes a test that failed on arm64. Nothing changes for users.

---

## 🔧 What's in this release

*   **🧹 SonarCloud: no open issues.** The root-helper function added in v1.2.5 (`run_root_helper()` in the PAM module) was flagged as too complex: a cognitive complexity of 40 against SonarCloud's limit of 25. It is now split into small helpers for pipe setup, stdin/stdout wiring, the uid-0 spawn, writing the input, reading the output and waiting for the child. Behaviour is unchanged.
*   **🧪 Test fix for arm64.** The arm64 release build runs under qemu emulation, where starting a missing helper binary starts the child, which then exits 127, instead of failing at spawn. The test now accepts either way, because both mean the helper failed. This made the v1.2.5 GitHub Release build fail on arm64. The fix was released by re-tagging v1.2.5.

No product behaviour changes, no new config keys and no new or changed translatable strings. The v1.2.5 security fix is unchanged.

---

## 📥 Installation (from Release assets)

Verify downloads against `SHA256SUMS` on the Release page before installing. Download this release's assets into an empty/clean directory before running these commands — the wildcards below match by filename pattern, and leftover assets from another version in the same directory can make a package manager see multiple matches (or, for the AppImage command, pass a second matched file as a stray argument).

| Format | Command |
|--------|---------|
| **Debian** (amd64 + arm64) | `sudo apt install ./ubuntu-hello_*_$(dpkg --print-architecture).deb ./ubuntu-hello-gtk_*_$(dpkg --print-architecture).deb` |
| **Fedora** (amd64 + arm64) | `sudo dnf install ./ubuntu-hello-[0-9]*fc44*.$(uname -m).rpm ./ubuntu-hello-gtk-*fc44*.$(uname -m).rpm` |
| **openSUSE** (amd64 + arm64) | `sudo zypper install ./ubuntu-hello-[0-9]*lp160*.$(uname -m).rpm ./ubuntu-hello-gtk-*lp160*.$(uname -m).rpm` |
| **AppImage** (amd64 + arm64) | `chmod +x Ubuntu-Hello-*-$(uname -m).AppImage && ./Ubuntu-Hello-*-$(uname -m).AppImage --install` |
| **Arch** (amd64 only) | `sudo pacman -U ./ubuntu-hello-[0-9]*.pkg.tar.zst ./ubuntu-hello-gtk-*.pkg.tar.zst` |
| **Snap** (amd64 only) | `sudo snap install --dangerous --classic ubuntu-hello_*_amd64.snap && sudo snap run ubuntu-hello.host-install` |
| **Flatpak** (amd64 only) | `flatpak install --user ./com.github.ventura8.UbuntuHello-*.flatpak && flatpak run --command=ubuntu-hello-host-install com.github.ventura8.UbuntuHello` |

PPA (Ubuntu 22.04, 24.04 and 26.04). **On 22.04 use the PPA**: the `.deb` assets above are built on 26.04:

```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello && sudo apt update && sudo apt install ubuntu-hello
```

Optional source install: download [`install.sh`](https://github.com/ventura8/ubuntu-hello/blob/v1.2.6/install.sh) from the **v1.2.6** tag, review it, then run locally — do not pipe a moving branch URL directly to `bash`.
