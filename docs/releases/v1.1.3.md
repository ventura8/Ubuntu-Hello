# 🚀 Ubuntu Hello v1.1.3 Release

Welcome to the **v1.1.3** release of **Ubuntu Hello**! This release adds **multi-format GitHub Release artifacts** — every `v*` tag now ships `.deb`, Fedora and openSUSE RPM, Arch packages, a classic Snap, an installer-style AppImage, and an installer-style Flatpak bundle. Post-install logic is centralized so all packagers behave consistently, and CI smoke-builds every format on eligible (non-fork) pull requests.

---

## ✨ Key Enhancements in v1.1.3

*   **📦 Multi-format GitHub Releases**:
    *   New [`.github/workflows/release.yml`](../../.github/workflows/release.yml) replaces `ppa-release.yml`: parallel build jobs upload artifacts, merge into a single Release with `SHA256SUMS`, and use authored `docs/releases/v*_github_description.md` bodies when present.
    *   Packaging metadata under [`packaging/`](../../packaging/) — Arch PKGBUILD (split packages), Fedora/openSUSE RPM specs, Snap (`classic`), AppImage, Flatpak manifest.
    *   Release Docker images: [`docker/Dockerfile.rpm.fedora`](../../docker/Dockerfile.rpm.fedora), [`docker/Dockerfile.rpm.opensuse`](../../docker/Dockerfile.rpm.opensuse), [`docker/Dockerfile.arch`](../../docker/Dockerfile.arch), [`docker/Dockerfile.release`](../../docker/Dockerfile.release).
    *   Driver scripts: [`scripts/release-{deb,rpm,arch,portable}.sh`](../../scripts/) + [`scripts/packaging-smoke-verify.sh`](../../scripts/packaging-smoke-verify.sh).
*   **🔧 Shared post-install helpers**:
    *   [`scripts/package-configure.sh`](../../scripts/package-configure.sh) — dlib, models, permissions, config restore, PAM, polkit override.
    *   [`scripts/package-gtk-onboard.sh`](../../scripts/package-gtk-onboard.sh) — setup wizard when no models enrolled.
    *   [`scripts/package-prerm.sh`](../../scripts/package-prerm.sh) — removal + keyring restore.
    *   Installed to `/usr/share/ubuntu-hello/` via Meson; Debian postinst/prerm thin wrappers source them.
*   **🖥️ AppImage / Flatpak installer model**:
    *   Portable artifacts bundle Meson output; one-time elevated host install via polkit + [`packaging/flatpak/install-host.sh`](../../packaging/flatpak/install-host.sh) (PAM cannot live in a sandbox).
*   **🧪 Tests & CI**:
    *   [`tests/test_packaging_release.py`](../../tests/test_packaging_release.py) — static packaging metadata and workflow checks.
    *   [`check.yml`](../../.github/workflows/check.yml) packaging smoke jobs: deb, Fedora RPM, openSUSE RPM, Arch, Snap, AppImage, Flatpak.
*   **📚 Docs / agents**:
    *   [`.agents/skills/release-packaging/SKILL.md`](../../.agents/skills/release-packaging/SKILL.md) runbook; updated [`AGENTS.md`](../../AGENTS.md), [`INSTRUCTIONS.md`](../INSTRUCTIONS.md), release skill install template.
    *   Legacy Arch path stub: [`ubuntu-hello/archlinux/ubuntu-hello/README.md`](../../ubuntu-hello/archlinux/ubuntu-hello/README.md) → `packaging/arch/`.

## 📥 Installation

Download assets from the [GitHub Release](https://github.com/ventura8/ubuntu-hello/releases/tag/v1.1.3) page.

### Method 1: Quick Install (from release tag)
Download and review [`install.sh`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/install.sh) from the **v1.1.3** tag, then run `bash install.sh` locally. Verify packaged Release assets against `SHA256SUMS` before installing downloads.

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```

### Method 3: Debian `.deb`
```bash
sudo apt install ./ubuntu-hello_1.1.3-1ppa1_amd64.deb ./ubuntu-hello-gtk_1.1.3-1ppa1_all.deb
```

### Method 4: Fedora RPM
```bash
sudo dnf install ./ubuntu-hello-1.1.3-1.fc44.x86_64.rpm ./ubuntu-hello-gtk-1.1.3-1.fc44.x86_64.rpm
```

### Method 5: openSUSE RPM
```bash
sudo zypper install ./ubuntu-hello-1.1.3-1.lp160.x86_64.rpm ./ubuntu-hello-gtk-1.1.3-1.lp160.x86_64.rpm
```

### Method 6: Arch Linux
```bash
sudo pacman -U ubuntu-hello-1.1.3-1-x86_64.pkg.tar.zst ubuntu-hello-gtk-1.1.3-1-x86_64.pkg.tar.zst
```

### Method 7: Snap (classic)
```bash
sudo snap install --dangerous --classic ubuntu-hello_1.1.3_amd64.snap
sudo snap run ubuntu-hello.host-install
```
The `configure` hook sets up models/config/PAM-config/polkit automatically on install, but the PAM module itself (`pam_ubuntu_hello.so`) ships inside the snap payload and must be copied onto the host with `host-install` before authentication will work.

### Method 8: AppImage (installer)
```bash
chmod +x Ubuntu-Hello-1.1.3-x86_64.AppImage
./Ubuntu-Hello-1.1.3-x86_64.AppImage --install
```

### Method 9: Flatpak (installer)
```bash
flatpak install --user ./com.github.ventura8.UbuntuHello-1.1.3-x86_64.flatpak && \
    flatpak run --command=ubuntu-hello-host-install com.github.ventura8.UbuntuHello && \
    flatpak run com.github.ventura8.UbuntuHello
```
Approve the polkit prompt on the host-install step to install PAM and system files.
