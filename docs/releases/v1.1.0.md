# 🚀 Ubuntu Hello v1.1.0 Release

Welcome to the **v1.1.0** release of **Ubuntu Hello**! This release expands **first-class multi-desktop compatibility** across **GNOME, KDE Plasma, XFCE, Cinnamon, MATE, Budgie, and LXQt**, hardens the PAM authentication lifecycle (greeter face-skip, process-group cancel, SIGTERM cleanup), adds software AES-256-GCM (`UH1:`) keyring blobs with `PAM_AUTHTOK` unlock for **GNOME Keyring and KWallet**, and rebuilds CI into fail-fast lint / coverage / **parallel per-DE compat** stages with Dockerfiles under `docker/`.

---

## ✨ Key Enhancements in v1.1.0

*   **🖥️ Additional Desktop Compatibility (all supported DEs)**:
    *   Face auth via `common-auth` stays **desktop-agnostic** and works with **GDM, SDDM, LightDM**, and similar greeters.
    *   Explicit product + CI coverage for **every** supported desktop:
        *   **GNOME / Ubuntu** — theme follow + GNOME Keyring (`pam_gnome_keyring`)
        *   **KDE Plasma** — theme follow + **KWallet** (`pam_kwallet5` / `libpam-kwallet5`)
        *   **XFCE** — theme follow + GNOME Keyring when present
        *   **Cinnamon** — theme follow + GNOME Keyring when present
        *   **MATE** — theme follow + GNOME Keyring when present
        *   **Budgie** — theme follow + GNOME Keyring when present
        *   **LXQt** — theme follow (best-effort) + GNOME Keyring when present
    *   Shared `theme_detect.py` dark/light probes for all seven DEs (settings window + auth overlay).
    *   `wallet_backend.py` labels the active session wallet (`gnome-keyring`, `kwallet`, or `none`) so CLI/GTK copy matches the desktop.
    *   Dedicated parallel CI compat cells (one Dockerfile + image each): `baseline`, `gnome`, `kde`, `xfce`, `cinnamon`, `mate`, `budgie`, `lxqt`.
*   **⏭️ Greeter Face-Skip After Failure**:
    *   After a completed non-zero face compare on greeter/login PAM services (`gdm-password`, `lightdm*`, `sddm*`, `login`, `*screensaver*`), PAM writes `/run/ubuntu-hello/face-skip/<user>` so the next attempt returns `PAM_AUTHINFO_UNAVAIL` (no camera flash) until success or `pam_sm_setcred` clears the marker.
    *   Controlled by `core.skip_face_after_failure` (default `true`). Does not apply to `sudo` / polkit.
*   **🔐 AES-GCM Keyring (`UH1:`) + Wallet Unlock**:
    *   Software keyring blob format `UH1:` (AES-256-GCM) alongside TPM paths; after a successful face match, PAM sets `PAM_AUTHTOK` for downstream `pam_gnome_keyring` / `pam_kwallet5`.
    *   Same sealed credential path for GNOME Keyring **and** KWallet — no second blob format.
*   **🧹 Auth Lifecycle Hardening**:
    *   Compare is spawned in its own process group; cancel sends `SIGTERM` to the group then `SIGKILL` after grace so the GTK overlay is not orphaned.
    *   `compare.py` handles `SIGTERM`/`SIGINT` with camera `release()`, GTK terminate/wait, then `os._exit(12)` (default SIGTERM does not run `atexit`).
*   **🧪 CI Split Gate (Ubuntu 26.04)**:
    *   Lint, coverage, and per-DE compat are separate stages (`docker/Dockerfile.ci.lint`, `.coverage`, and per-DE images under `docker/`).
    *   Local `./scripts/ci-pipeline.sh` runs lint → coverage → parallel compat matrix fail-fast between stages; GHA runs lint + coverage in parallel, then compat `needs` both.
    *   Root kept clean: all CI/PPA Dockerfiles live under `docker/`; BuildKit caching via `UH_CI_DOCKER_CACHE`.
*   **📚 Agent Workspace & Docs**:
    *   Canonical `AGENTS.md`, focused `.agents/skills/*/SKILL.md` runbooks (including this release skill), architecture deep dive, and contributor `docs/INSTRUCTIONS.md`.

## 📥 Installation

### Method 1: Quick Install (Recommended)
Open your terminal and run the universal installer:
```bash
curl -fsSL https://raw.githubusercontent.com/ventura8/ubuntu-hello/master/install.sh | sudo bash
```

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```

### Method 3: Debian / Manual Package
Download the attached `.deb` package for your architecture, then install it using `apt` or `gdebi`:
```bash
sudo apt install ./ubuntu-hello_1.1.0-1ppa1_amd64.deb
```
