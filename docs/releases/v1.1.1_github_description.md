# Ubuntu Hello v1.1.1 - Wallet Restore on Uninstall & Hardened Post-Install

This patch restores the **login keyring or KWallet** password from sealed credentials **before** uninstall / `apt remove` deletes `/etc/ubuntu-hello`, hardens the post-install setup wizard (skip when faces are already enrolled; lock/log under `/run/ubuntu-hello/` instead of `/tmp`), and tightens `ubuntu-hello keyring restore` so a bare restore targets the selected user while `restore --all` is the explicit multi-user sweep used by packaging.

---

## 🔐 Uninstall Wallet Restore

*   `uninstall.sh` and `debian/ubuntu-hello.prerm` run `timeout 120 ubuntu-hello keyring restore --all` **before** deleting seals.
*   New `keyring_restore.py` unseals TPM or `UH1:` login passwords over each user’s session bus (password never logged; failures do **not** abort removal).
*   **GNOME Keyring** (`pam_gnome_keyring`): D-Bus `ChangeWithMasterPassword` (old=new=sealed `P`). Succeeds when the wallet already unlocks with `P`; cannot discover a divergent wallet password.
*   **KWallet** (`pam_kwallet5`): verification-only `pamOpen` with PBKDF2-SHA512 hash. Does **not** reset the wallet password — set it in System Settings if it still mismatches.
*   `ubuntu-hello keyring disable` remains delete-only.

---

## 🖥️ Desktop, Greeter & Wallet Compatibility

Face authentication via PAM (`common-auth`) remains **desktop-agnostic** and works with **GDM, SDDM, LightDM**. Restore uses a **private** D-Bus connection per user’s `DBUS_SESSION_BUS_ADDRESS`:

| Desktop | Face auth | Theme follow | Session wallet auto-unlock | Uninstall restore |
|---------|-----------|--------------|----------------------------|-------------------|
| **GNOME / Ubuntu** | Yes | Yes | GNOME Keyring (`pam_gnome_keyring`) | `ChangeWithMasterPassword` |
| **KDE Plasma** | Yes | Yes | **KWallet** (`pam_kwallet5`) | `pamOpen` verification |
| **XFCE** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
| **Cinnamon** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
| **MATE** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
| **Budgie** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |
| **LXQt** | Yes | Yes | GNOME Keyring when present | GNOME Keyring path |

*   **CI compat matrix** (parallel, Ubuntu 26.04): `baseline`, `gnome`, `kde`, `xfce`, `cinnamon`, `mate`, `budgie`, `lxqt`. Coverage stage now includes `keyring_restore` at 100%.

---

## 🧹 Hardened Post-Install Wizard

*   Wizard launches **only when no face models are enrolled** (`install.sh` + `ubuntu-hello-gtk` postinst; core postinst does not double-launch).
*   Symlink-only files under `models/` do not count as enrollment (`lstat` + regular-file check).
*   Lock/log live under `/run/ubuntu-hello/` (`0700` / `0600`, `O_NOFOLLOW`) — not world-writable `/tmp`. Fallback: `sudo cat /run/ubuntu-hello/postinstall.log`.

---

## 🧰 Keyring CLI

*   `ubuntu-hello keyring restore` — selected user (`-U` / elevation).
*   `ubuntu-hello keyring restore --all` — every sealed user (uninstall / prerm).
*   Extra args and positional usernames are usage errors. Restore strings filled for all Whisper locales.


```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```
