# Ubuntu Hello v1.1.3 - Multi-Format GitHub Release Artifacts

Every `v*` tag now ships **seven artifact families** on GitHub Releases: Debian `.deb`, Fedora RPM, openSUSE RPM, Arch `.pkg.tar.zst`, classic Snap, installer AppImage, and installer Flatpak — plus `SHA256SUMS`. Post-install logic is shared across packagers, and CI smoke-builds every format on eligible (non-fork) pull requests.

---

## 📦 Multi-Format Releases

*   **Workflow**: [`.github/workflows/release.yml`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/.github/workflows/release.yml) — parallel builds → artifact upload → GitHub Release with authored notes from `docs/releases/v*_github_description.md`.
*   **Metadata**: [`packaging/`](https://github.com/ventura8/ubuntu-hello/tree/v1.1.3/packaging) — Arch PKGBUILD, Fedora/openSUSE specs, Snap, AppImage, Flatpak manifest.
*   **Docker**: [`docker/Dockerfile.rpm.fedora`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/docker/Dockerfile.rpm.fedora), [`docker/Dockerfile.rpm.opensuse`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/docker/Dockerfile.rpm.opensuse), [`docker/Dockerfile.arch`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/docker/Dockerfile.arch), [`docker/Dockerfile.release`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/docker/Dockerfile.release).
*   **Drivers**: [`scripts/release-{deb,rpm,arch,portable}.sh`](https://github.com/ventura8/ubuntu-hello/tree/v1.1.3/scripts), [`scripts/packaging-smoke-verify.sh`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/scripts/packaging-smoke-verify.sh).

## 🖥️ Portable Installers (AppImage / Flatpak)

PAM modules cannot run inside a sandbox. AppImage and Flatpak bundles include a **one-time elevated host install** (`--install` / polkit) via [`packaging/flatpak/install-host.sh`](https://github.com/ventura8/ubuntu-hello/blob/v1.1.3/packaging/flatpak/install-host.sh).

## 📥 Installation (from Release assets)

Verify downloads against `SHA256SUMS` on the Release page before installing.

| Format | Command |
|--------|---------|
| **Debian** | `sudo apt install ./ubuntu-hello_*_amd64.deb ./ubuntu-hello-gtk_*_all.deb` |
| **Fedora** | `sudo dnf install ./ubuntu-hello-[0-9]*fc44*.rpm ./ubuntu-hello-gtk-*fc44*.rpm` |
| **openSUSE** | `sudo zypper install ./ubuntu-hello-[0-9]*lp160*.rpm ./ubuntu-hello-gtk-*lp160*.rpm` |
| **Arch** | `sudo pacman -U ./ubuntu-hello-[0-9]*.pkg.tar.zst ./ubuntu-hello-gtk-*.pkg.tar.zst` |
| **Snap** | `sudo snap install --dangerous --classic ubuntu-hello_*.snap && sudo snap run ubuntu-hello.host-install` |
| **AppImage** | `chmod +x Ubuntu-Hello-*-x86_64.AppImage && ./Ubuntu-Hello-*-x86_64.AppImage --install` |
| **Flatpak** | `flatpak install --user ./com.github.ventura8.UbuntuHello-*.flatpak && flatpak run --command=ubuntu-hello-host-install com.github.ventura8.UbuntuHello && flatpak run com.github.ventura8.UbuntuHello` |

PPA remains available:

```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello && sudo apt update && sudo apt install ubuntu-hello
```

Optional source install: download `install.sh` from the [v1.1.3 tag](https://github.com/ventura8/ubuntu-hello/tree/v1.1.3), review it, then run locally — do not pipe a moving branch URL directly to `bash`.
