# 🚀 Ubuntu Hello v1.0.4 Release

Welcome to the **v1.0.4** release of **Ubuntu Hello**! This release brings a comprehensive visual modernization conforming to modern Ubuntu 26.04 (Yaru style / GNOME HIG) aesthetics, including client-side titlebars (HeaderBars), dynamic accent/theme synchronization, layout fixes for webcam previews, host animation synchronization, and async webcam thread optimization to eliminate interface freezes.

---

## ✨ Key Enhancements in v1.0.4

*   **🎨 Ubuntu 26.04 CSD Theme Integration**:
    *   Replaced standard window decoration with integrated client-side `GtkHeaderBar` titlebars in both the Setup Wizard (`onboarding.py`) and Configuration Settings (`window.py`) windows.
    *   Applied standard GTK symbolic variables (like `@theme_selected_bg_color` and `@theme_selected_fg_color`) to styling widgets, ensuring the application UI adapts dynamically to the user's desktop accent color and dark/light modes.
    *   Styled secondary buttons as clean flat buttons and styled the configurator notebook tabs into a vertical sidebar layout.
*   **📷 Aspect-Fit & Non-Cropping Webcam Previews**:
    *   Fixed webcam preview layout constraints to scale the camera feed to fill the widescreen container without cropping the feed or pushing list views/navigation buttons out of bounds.
*   **⚡ Non-Blocking UI Webcam Initialization**:
    *   Offloaded webcam hardware checks and initialization (`cv2.VideoCapture`) to a background daemon thread, eliminating the annoying 1-second GUI freeze when loading the Video tab or switching between webcam devices.
*   **🎬 Native Animation Preferences Synchronization**:
    *   Synced window transitions and stack animations with the user's host desktop preference (`org.gnome.desktop.interface enable-animations`), ensuring elevated runtimes (e.g. running via `pkexec`) follow uniform desktop animation settings.

## 📥 Installation

### Method 1: Quick Install (Recommended)
Open your terminal and run the universal installer:
```bash
curl -fsSL https://raw.githubusercontent.com/ventura8/ubuntu-hello/master/install.sh | sudo bash
```

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```

### Method 3: Debian / Manual Package
Download the attached `.deb` package for your architecture, then install it using `apt` or `gdebi`:
```bash
sudo apt install ./ubuntu-hello_1.0.4-1ppa1_amd64.deb
```
