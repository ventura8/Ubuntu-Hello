# 🚀 Ubuntu Hello v1.2.6 Release

Welcome to the **v1.2.6** release of **Ubuntu Hello**! This is a maintenance release: it clears the last open SonarCloud issue in the PAM module and fixes a test that failed on arm64. Nothing changes for users.

---

## ✨ What's in v1.2.6

*   **🧹 SonarCloud: no open issues.** The root-helper function added in v1.2.5 (`run_root_helper()` in the PAM module) was flagged as too complex: a cognitive complexity of 40 against SonarCloud's limit of 25. It is now split into small helpers for pipe setup, stdin/stdout wiring, the uid-0 spawn, writing the input, reading the output and waiting for the child. Behaviour is unchanged.
*   **🧪 Test fix for arm64.** The arm64 release build runs under qemu emulation, where starting a missing helper binary starts the child, which then exits 127, instead of failing at spawn. The test now accepts either way, because both mean the helper failed. This made the v1.2.5 GitHub Release build fail on arm64. The fix was released by re-tagging v1.2.5.

No product behaviour changes, no new config keys and no new or changed translatable strings. The v1.2.5 security fix is unchanged.

## 📥 Installation

Download assets from the [GitHub Release](https://github.com/ventura8/ubuntu-hello/releases/tag/v1.2.6) page. Verify against `SHA256SUMS` before installing. Download this release's assets into an empty/clean directory before running these commands — the wildcards below match by filename pattern, and leftover assets from another version in the same directory can make a package manager see multiple matches (or, for the AppImage command, pass a second matched file as a stray argument).

### Method 1: Quick Install (from release tag)
Download and review [`install.sh`](https://github.com/ventura8/ubuntu-hello/blob/v1.2.6/install.sh) from the **v1.2.6** tag, then run `bash install.sh` locally.

### Method 2: PPA (Ubuntu / Linux Mint)
```bash
sudo add-apt-repository ppa:ventura8/ubuntu-hello
sudo apt update
sudo apt install ubuntu-hello
```
Builds for Ubuntu **22.04 (jammy)**, 24.04 (noble) and 26.04 (resolute), and derivatives on them (Linux Mint 21 / 22). **On 22.04, use the PPA**: the `.deb` Release assets below are built on 26.04 and do not install there.

### Method 3: Debian `.deb` (amd64 + arm64)
```bash
sudo apt install ./ubuntu-hello_*_$(dpkg --print-architecture).deb ./ubuntu-hello-gtk_*_$(dpkg --print-architecture).deb
```

### Method 4: Fedora RPM (amd64 + arm64)
```bash
sudo dnf install ./ubuntu-hello-[0-9]*fc44*.$(uname -m).rpm ./ubuntu-hello-gtk-*fc44*.$(uname -m).rpm
```

### Method 5: openSUSE RPM (amd64 + arm64)
```bash
sudo zypper install ./ubuntu-hello-[0-9]*lp160*.$(uname -m).rpm ./ubuntu-hello-gtk-*lp160*.$(uname -m).rpm
```

### Method 6: Arch Linux (amd64 only)
```bash
sudo pacman -U ./ubuntu-hello-[0-9]*.pkg.tar.zst ./ubuntu-hello-gtk-*.pkg.tar.zst
```

### Method 7: Snap (classic, amd64 only)
```bash
sudo snap install --dangerous --classic ubuntu-hello_*_amd64.snap
sudo snap run ubuntu-hello.host-install
```

### Method 8: AppImage (installer, amd64 + arm64)
```bash
chmod +x Ubuntu-Hello-*-$(uname -m).AppImage
./Ubuntu-Hello-*-$(uname -m).AppImage --install
```

### Method 9: Flatpak (installer, amd64 only)
```bash
flatpak install --user ./com.github.ventura8.UbuntuHello-*.flatpak && \
    flatpak run --command=ubuntu-hello-host-install com.github.ventura8.UbuntuHello
```
Approve the polkit prompt on the host-install step to install PAM and system files.
